Altara — Key Setup

where every api key lives · click a card to open
How this works: every key you collect goes into one file called .env inside your cb-agent folder. Open that file with Notepad, find the matching line, and paste the key right after the = sign. No spaces, no quotation marks. Save the file when you're done.

Never paste a key into a chat, email, or screenshot. They're passwords.

Anthropic (Claude)the agent's brain — nothing works without it
Required▶
console.anthropic.com
  1. Go to console.anthropic.com and sign up. This is separate from your Claude.ai subscription — it's billed on its own.
  2. Add a payment method and buy credits. $10–20 is plenty to start.
  3. In the left menu click API keys.
  4. Click Create Key, give it any name.
  5. Copy the key immediately — it starts with sk-ant- and is only shown once.
paste into .env here
ANTHROPIC_API_KEY=sk-ant-...
2
Klaviyoemail + SMS list growth — 2 minutes, no waiting
Easiest▶
klaviyo · settings → api keys
  1. In Klaviyo, click your account name (bottom left) → Settings.
  2. Click the API keys tab.
  3. Click Create Private API Key. The public key won't work — it can only add subscribers, not read them.
  4. Choose Custom Key. Set Lists = Read and Profiles = Read. Leave everything else on No Access.
  5. Copy the key (starts with pk_) — shown once only.
paste into .env here
KLAVIYO_PRIVATE_KEY=pk_...
Why read-only? This key sits in a text file on your computer. Read-only means a leak exposes your subscriber count. Full access would let someone email your whole list or delete it.

Instagram + Meta Adsone app covers both — ~30 min
Longest▶
Before you start: @cb-agent.st must be a Business/Creator account and linked to a Facebook Page. Check in Instagram: Settings → Professional Dashboard → Page. Without this link, nothing below will work.
developers.facebook.com · your app
  1. Go to developers.facebook.com → My Apps → Create App → choose type Business.
  2. Left menu → Use cases → Add use cases. Add Manage messaging & content on Instagram and Measure ad performance data with Marketing API. Click Save.
  3. On the Instagram use case click Customize → in the left menu pick API setup with Facebook login → click "Add required content permissions". Skip the messaging button.
  4. Still there, click Permissions and features and add instagram_manage_insights. This is the one that gives you reach and saves.
  5. On the ads use case → Customize → add ads_read.
  6. Go to Settings ▸ Basic. Copy the App ID and App Secret into .env.
  7. Top menu → Tools ▸ Graph API Explorer. Pick your app, add your permissions, click Generate Access Token, approve the popup.
  8. Go to Tools ▸ Access Token Debugger. Paste the token → Debug → scroll down → Extend Access Token. Copy the longer one.
  9. Back in Graph API Explorer run me/accounts → copy your Page id. Then run {page-id}?fields=instagram_business_account → that number is your IG Business ID.
  10. Your ad account ID is in the Ads Manager web address — act_ plus the digits.
paste into .env here
IG_BUSINESS_ID=17841...
META_AD_ACCOUNT_ID=act_123...
META_APP_ID=...
META_APP_SECRET=...
The token itself does NOT go in .env. Leave META_ACCESS_TOKEN blank. Instead run python agent.py auth meta and paste it at the prompt — that checks the token works and turns on automatic renewal, so it never expires on you.

TikTokneeds review — submit early, wait a few days
Optional▶
  1. Go to developers.tiktok.com → sign in → Manage apps → Create app.
  2. Add the Login Kit product.
  3. Request only two scopes: user.info.basic and video.list. Asking for more hurts your approval odds.
  4. Set Redirect URI to http://localhost:8377/callback
  5. Submit for review — takes a few days.
  6. When approved, copy the Client key and Client secret into .env, then run python agent.py auth tiktok.
paste into .env here
TIKTOK_CLIENT_KEY=...
TIKTOK_CLIENT_SECRET=...
TIKTOK_REDIRECT_URI=http://localhost:8377/callback
5
Shopifysales data + website editing
Optional▶
  1. Shopify admin → Settings → Apps and sales channels.
  2. Click Develop apps → Create an app. Name it "CB Agent".
  3. Click Configure Admin API scopes and tick these four: read_products read_orders read_themes write_themes
  4. Save → Install app.
  5. Copy the Admin API access token (starts with shpat_) — shown once.
  6. Your store name is the .myshopify.com address, not cb-agent.st.
paste into .env here
SHOPIFY_STORE=your-store.myshopify.com
SHOPIFY_ADMIN_TOKEN=shpat_...
Before using site editing: in Shopify go to Online Store → Themes → (...) → Duplicate your live theme and rename it to include the word "draft". All agent edits go there, so your live store is never touched until you publish.
When you're done: save .env, then double-click 2 - START AGENT.bat and check the tiles on the dashboard. Anything showing STANDBY means that key isn't being read — usually a typo, a stray space after the =, or the file was saved as .env.txt instead of .env.
